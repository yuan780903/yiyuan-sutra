# 依願選經｜念經定課與經文朗讀

依需求挑選經典、閱讀完整經文並以裝置語音自動朗讀的單頁網站，採少女漫畫風格設計。

## 功能

| 功能 | 說明 |
|---|---|
| 依需求選經 | 六種需求對應推薦經典與網友心得 |
| 完整經文 | 藥師經、普門品、金剛經、普賢行願品、地藏經、楞嚴經、法華經、華嚴經（八十卷） |
| 自動朗讀 | 逐句朗讀並標示位置，可點句開始、調整語速與字級 |
| 集經續念 | 暫停後記住位置，下次開啟可接續 |
| 一日定課 | 《地藏經》念完自動接續《普賢行願品》 |
| 祈請與迴向 | 可開關，文字可自訂 |

## 使用方式

單一靜態檔案 `index.html`，無需建置。啟用 GitHub Pages（Settings → Pages → Branch: `main` / root）後即可透過網址瀏覽。朗讀功能需裝置內建中文語音。

## 資料來源與授權

- 經文：CBETA 電子佛典集成（財團法人佛教電子佛典基金會），《大正新脩大藏經》數位版及新式標點。依 CBETA 授權，**僅供非商業使用**。
- 念經心得：整理自東森財經新聞 2026-05-13 報導之網友分享，屬個人經驗，效果因人而異，不構成醫療、財務或任何專業建議。
- 網站中的漫畫角色為原創 SVG 插畫。
